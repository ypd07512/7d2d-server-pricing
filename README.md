## 七日杀到底要多少配置：一份 2022 年的社区指南说了什么，没说什么

中文圈流传最广的一份七日杀开服指南写在 Steam 社区，2022 年 4 月创建、当年 8 月更新，给出的硬件基线是**腾讯云轻量 2 核 4G“基本够用”**，系统选 Windows Server 2012 R2，登录用 Administrator，远程走 mstsc。

这句话要打折听。它没写清楚是几个人玩、装没装 MOD、地图多大，也没覆盖之后几个大版本的地图和僵尸 AI 变化。把它当成**最低线**而不是舒适线更稳妥：2 到 4 人、不装大型 MOD 包，2 核 4G 能跑；上到 6 人以上，或者要装 overhaul 类 MOD、开大图，内存往 8G 走。

那份指南选的 Windows Server 2012 R2 现在也太老了，装系统的时候挑一个还在支持期内的版本。

真正卡人的不是 CPU，是内存和单核主频。七日杀的服务端在玩家分散、僵尸成群的时候会有一个明显的单核峰值，游戏云那套 5.7GHz、5.8GHz 的机器就是冲这个来的。

## 面板一键开服和裸 VPS 自装，差的是这五步

自己装一遍，流程是这样的：

1. **拿服务端文件。** Steam 专用服务器 App ID 是 **294420**。在服务器上装 SteamCMD，执行 `steamcmd +login anonymous +app_update 294420 validate +quit`。不想敲命令，Steam 客户端库里直接搜 294420 也能下到同一份服务端。
2. **放行端口。** 默认要开的是 **26900**。那份指南是在腾讯云轻量的防火墙里加一条“自定义 26900”，换到别的服务商就是在安全组或者防火墙里加同一条规则。
3. **改 serverconfig。** 服务端目录里用记事本打开 serverconfig，服务器名、人数上限、管理接口、存档位置、性能、僵尸和战利品倍率、土地所有权都在这个文件里，十来栏。改完保存，启动程序。
4. **处理公网 IP。** 机器没有公网 IP 的话，三人以下可以用异地组网工具（指南里用的是蒲公英）加入房主 IP，走局域网联机；想正经开服，电信宽带可以打客服电话申请公网 IP。
5. **管更新。** 指南末尾列了一串 Windows 小工具：condenser 用来下载、配置、启动服务端，SteamCMD AutoUpdater 负责自动更新，SteamCMD GUI 让你不碰命令行，还有 NaiwazBot 这类网页控制面板。不装这些，每次游戏更新都得手动重跑一遍 SteamCMD，装了 MOD 还要同步给每个玩家。

面板服的差别就在这五步被压成了一步：选游戏、点启动。代价是权限受面板限制，MOD 和配置文件不一定能随便改，面板游戏列表里没有的游戏也开不了。MCSM 面板预置的主要是 Minecraft、泰拉瑞亚、饥荒这类，七日杀在不在你选的那个面板的列表里，下单前先在控制台里点开看一眼，别等付了钱才发现要自己装。

## 市面上其他报价长什么样

淘宝上搜七日杀服务器，能搜到两类完全不同的东西。

一类是“免搭建一键开服”的成品面板服，有卖家挂出的展示价是 **5 元**，评分 5.0。这个数字通常是首期价或者最低配展示价，页面没写配置、人数上限、续费价，实际下单会按你选的配置往上加。

另一类是标题里带“我的世界七日杀”的电信高防 VPS，展示价集中在 **49 元到 79 元**：宁波 100G 高防 79 元、襄阳 600G 高防 69 元、新宁波 100G 高防 49 元。这些是裸机器，系统和面板全要自己装，卖点是大带宽和高防，主要面向传奇、微端这类场景，CPU 和内存未必比同价的普通云服务器强。

两个数字量级差十几倍，卖的东西不一样：5 元买的是别人替你搭好的面板服，49 到 79 元买的是你要自己折腾的机器。都不能当“七日杀服务器市场均价”用，页面上的价格只是展示价，配置明细和续费价都没写。

还有一类按小时计费、关服只收很低保服费的游戏云，适合一周只开两晚的固定小队。雨云这边对应的做法是游戏云的动态计费，逻辑一样，都是让闲置时间不花钱。
